### Mục tiêu tuần 6:

* Tìm hiểu Cloud Observability (CloudWatch, CloudTrail, Systems Manager).
* Tìm hiểu Serverless Computing với AWS Lambda và Amazon API Gateway.

### Kết quả đạt được tuần 6:

* Tìm hiểu kiến thức cơ bản về giám sát với CloudWatch, ghi log với CloudTrail và SSM Session Manager.
* Tìm hiểu khái niệm Serverless REST API với API Gateway, AWS Lambda và DynamoDB (chưa thực hành).
* Tìm hiểu cách CloudWatch alarm giám sát Lambda function (chưa thực hành).
